# preview

## Purpose

Renders one pull request preview environment: OpenChoreo `Environment/pr-<n>-<component>` on the preview data plane, the project's `ProjectReleaseBinding` for it (cell namespace labelled `platform.koorikla.io/preview`) and `ReleaseBinding/<component>-pr-<n>` pinning `ComponentRelease/<component>-pr-<n>-<sha[:12]>`, which the auto-build pass cuts from the in-cluster build of the PR head. Only stock OpenChoreo objects, so the upstream ephemeral-environment resource can replace this chart later.

## Where it runs

- **Target:** `mgmt` cluster, OpenChoreo org namespace (`openchoreo.orgNamespace`), in `AppProject/previews`.
- **Selection:** Not a catalog addon; one `Application/preview-<component>-pr-<n>` per open pull request of an opted-in component, generated by `ApplicationSet/previews-<project>` (`charts/tenant`).

## Key values

- `project`, `component`, `pullRequest`, `commit`, `repository`, `branch`: from the pull request generator; malformed values fail the render.
- `expired`: `"true"` when the PR carries the expiry label; renders nothing, so Argo CD prunes the preview.
- `previews.dataPlane`, `openchoreo.orgNamespace`: from `installation.yaml`.
