# preview

## Purpose

Renders one pull request preview environment: OpenChoreo `Environment/pr-<n>-<component>` on the preview data plane, the project's `ProjectReleaseBinding` for it (cell namespace labelled `platform.koorikla.io/preview`) and `ReleaseBinding/<component>-pr-<n>` pinning `ComponentRelease/<component>-pr-<n>-<sha[:12]>`, which the auto-build pass cuts from the in-cluster build of the PR head. The same pass gives the preview its own instance of every Resource the app depends on (`ResourceReleaseBinding/<resource>-pr-<n>-<component>`, owned by the Environment, so it goes with the preview). Only stock OpenChoreo objects, so the upstream ephemeral-environment resource can replace this chart later.

## Where it runs

- **Target:** `mgmt` cluster, OpenChoreo org namespace (`openchoreo.orgNamespace`), in `AppProject/previews`.
- **Selection:** Not a catalog addon; one `Application/preview-<component>-pr-<n>` per open pull request of an opted-in component, generated by `ApplicationSet/previews-<project>` (`charts/tenant`).

| commit | string | `""` |  |

| pullRequest | string | `""` |  |
| repository | string | `""` |  |
| waiting | string | `"false"` | `"true"` when the PR carries `previews.waitingLabel`: the tenant is at its preview cap, the auto-build pass holds this PR (failed commit status) and removes the label when a slot frees (#385); renders nothing meanwhile. |
