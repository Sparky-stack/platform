# keda

## Purpose

Wrapper chart for KEDA (`2.21.0`) on workload clusters. Provides event-driven autoscaling (`ScaledObject` and `ScaledJob`) across all namespaces from Prometheus, Kafka, and external event sources.

## Where it runs

- **Roles / providers:** `roles: [workload]`, all providers (`namespace: keda`, `serverSideDiff: true`).
- **Catalog label:** `addons.platform.koorikla.io/keda` (`default: false`, opt-in with `"true"` per cluster via `addons.keda: true`).

## Key values

- `namespace.podSecurity`: `restricted` Pod Security admission label on namespace `keda`.
- `keda.crds.install`: `true` (applied server-side).
- `keda.certificates.autoGenerated`: `false` (uses cert-manager certificates).
- `keda.image.{keda,metricsApiServer,webhooks}`: `2.21.0` pinned by multi-arch index digest.
