## Decisions
- [argocd-agent Managed Mode Waits for Upstream 1.0](decisions/argocd-agent-managed-mode-waits-for-upstream.md) — Spike #20: managed mode works with our ApplicationSets (destination.name), but stays push mode until argocd-agent 1.0 and an invariant-3 decision; CAPI keeps the kubeconfig anyway.
- [Build Trigger Polling Locally, Webhook in Cloud, and GitHub App Tokens](decisions/build-trigger-polling-and-github-app-tokens.md) — Poll git locally and use HMAC webhooks in cloud with registry-aware rebuilds and per-repo GitHub App tokens (no PATs).
- [Fold koorikla/ci into Platform Repo and Pin Tooling with mise](decisions/fold-ci-into-platform-and-mise-toolchain.md) — Consolidate `koorikla/ci` workflows/scripts/toolbox into `koorikla/platform` (#213) and pin all CLI tools in `mise.toml`.
- [Helm, Crossplane, and OpenChoreo Building Blocks — No Kustomize or Flux](decisions/building-blocks-helm-crossplane-openchoreo.md) — Use Helm wrapper charts, Crossplane v2 Compositions, and OpenChoreo CRs pushed by Argo CD on `mgmt`; never Flux or Kustomize.
- [Local Platform Lab Scope, Single-Cluster Profile, BYO, and Cloud Examples](decisions/local-lab-scope-byo-and-cloud-examples.md) — Prove everything on Docker (`k3d` + single `dev1` CAPD cluster by default), support `provider: byo`, and ship cloud ClusterClasses as untested examples.
- [Merge capi-providers and clusterclasses into charts/cluster with Provider Folders](decisions/merge-clusterclasses-into-charts-cluster.md) — One CAPI chart: `charts/cluster/templates/<provider>/` + `common/`, `scope: fleet` (providers, ClusterClasses, app `cluster-fleet`) vs `scope: cluster` (#116).
- [One Mesh Umbrella Chart (addons/mesh)](decisions/mesh-umbrella-chart.md) — Ambient, istio-csr and the east-west gateway in one wrapper chart and one Argo app per cluster; member parts switched on by `values/mesh-member.yaml`.
- [OpenBao as Local Mesh CA with Pluggable Cloud CA](decisions/openbao-mesh-ca-and-pluggable-cloud-ca.md) — Keep mesh CA private keys inside OpenBao on `mgmt` (`istio-csr` on members) behind a standard cert-manager `Issuer` contract pluggable in cloud.
- [OSS crossplane-contrib Upjet Providers Only](decisions/crossplane-oss-upjet-providers-only.md) — Standardize on open-source `crossplane-contrib` Upjet family providers plus `CloudNativePG` locally, avoiding commercial Upbound packages.
- [PR Preview Environments Design](decisions/pr-preview-environments.md) — Render per-PR OpenChoreo `Environment` + bindings via `charts/preview` with a 48h Kyverno TTL and `occ remote` inner loop (#168).
- [Re-Bootstrap Over Long Live Repair and Nightly Rehearsal](decisions/rebootstrap-over-repair-and-nightly-rehearsal.md) — Prefer `task down` + `task up` over imperative live repair; enforce zero-touch convergence (~31 min to 45 Healthy apps) via bootstrap rehearsals.
- [Talos on Hetzner Waits for Upstream CACPPT Release](decisions/talos-on-hetzner-waits-for-upstream.md) — Switch Hetzner example from k3s to Talos once upstream Sidero CACPPT releases `TalosControlPlaneTemplate` (#189).

## Gotchas
- [Crossplane Project CLI - Paths Under apis/ and Derived Function Names](gotchas/crossplane-project-cli-paths-and-function-names.md) — `--path` is relative to `apis/`; the embedded function name derives from `spec.repository` + function dir, so build/push/CI must use the same repository (#240).
- [OpenChoreo Authz - Deny Is Per Entitlement Value; Developers Per Project](gotchas/openchoreo-authz-per-project-developers.md) — Upstream binds `developers` to write every project; a deny only revokes grants of the same group value. Org-wide read-only + per-project `AuthzRoleBinding` with the production condition in the allow (#335).
- [Preview Teardown - Stuck ResourceReleaseBinding and Re-created Tenant Descriptor](gotchas/preview-teardown-leaks.md) — The Environment must outlive the preview's ResourceReleaseBindings (blockOwnerDeletion + foreground); terminating bindings must not match the descriptor GeneratingPolicy.
- [Preview Cells - Tenant Secrets and CloudNativePG under Cilium](gotchas/preview-cells-tenant-secrets-and-cnpg.md) — Previews bind to their tenant's OpenBao role via Kyverno descriptors; CNPG pods need kube-apiserver egress that Cilium never grants via ipBlock (#267, #331).
- [OpenChoreo SecretReference Rotation and Scope](gotchas/openchoreo-secretreference-rotation-and-scope.md) — App secrets refresh in 15 s but pods need a restart; the store is platform-fixed; `targetPlane` belongs to the secrets API.
- [Argo CD Custom Health for Kyverno DeletingPolicy and Unmatched CRS](gotchas/argocd-custom-health-deletingpolicy-and-crs.md) — Kyverno `DeletingPolicy` never sets `Ready` and unmatched peers-only `ClusterResourceSet`s stay `Progressing` without custom Lua checks (#187, #198).
- [Argo CD Server-Side Diff Hides Changes to Argo Workflows Objects](gotchas/argocd-server-side-diff-atomic-crd-spec.md) — Atomic + preserve-unknown CRD `spec` makes server-side diff report Synced while a ClusterWorkflowTemplate stays old; addons rendering Argo Workflows kinds set `IncludeMutationWebhook=true` (#184).
- [Argo CD Server-Side Diff Deadlocks on Immutable Fields](gotchas/argocd-server-side-diff-immutable-fields.md) — A git change to an immutable field fails the dry-run apply, the app goes ComparisonError and `Force/Replace` never runs; immutable-spec kinds live in a `ServerSideDiff=false` addon (#281).
- [Argo CD Sync-Wave Ordering for CAPI Outputs and Unlimited Retry](gotchas/argocd-sync-wave-ordering-and-unlimited-retry.md) — Separate CAPI producers and consumers across sync waves and set `retry.limit: -1` (never `controller.sync.timeout.seconds`) (#192, #195, #199).
- [Helm values.schema.json vs Template required/fail](gotchas/helm-values-schema-vs-template-required.md) — `helm lint` passes a template `fail` but not a schema error: keys only installations fill keep their presence check in `templates/validate.yaml` (#116).
- [Docker Network Pool Exhaustion from crossplane render](gotchas/docker-network-pool-exhaustion-crossplane-render.md) — Share one Docker bridge network and function containers across `crossplane render` tests so Docker subnet pools don't exhaust (#181).
- [Gemini Transcript Ceiling and Token Discipline for Subagents](gotchas/gemini-transcript-ceiling-for-agents.md) — Read small file slices, skip Flux/Kustomize skill refs, keep writes `< 80` lines, and commit each step to avoid context cutoffs.
- [Helm Library Chart koorikla-lib (file:// Dependency)](gotchas/helm-library-chart-koorikla-lib.md) — Shared blocks live in `charts/lib`; omit its values scope from `.Values` dumps, re-package `file://` deps in `hack/deps.sh`, test through `charts/lib-test` (#116).
- [Istio Ambient Port 15008 in Cell Policies and Telemetry DNS on *.localhost](gotchas/istio-ambient-port-15008-and-telemetry-dns.md) — Open TCP `15008` (HBONE) in cell NetworkPolicies and allow kubelet probes from ambient's SNAT source `169.254.7.127/32`, and keep `telemetry` out of ambient mesh so `ztunnel` DNS capture doesn't break `*.localhost` (#53, #206, #208, #251).
- [mise Global vs Repo Tool Versions and Python Env Var Leakage](gotchas/mise-global-vs-repo-tool-versions.md) — Always run `mise trust` and prefix commands with `env -u PYTHONHOME -u PYTHONPATH -u PYTHON PATH=/usr/bin:$PATH mise exec --` inside the worktree (#171).
- [OpenBao Policies Only at Init, Policy Reconciler, and Wave -1 Seal Key](gotchas/openbao-policies-init-and-reconciler.md) — Reconcile `tenant-*` policies via a post-init job and sync `openbao-unseal` in wave `-1` before the StatefulSet (#96, #179, #190, #191).
- [OpenChoreo ReleaseBinding Ordering and Fresh Local Harbor Digests](gotchas/openchoreo-releasebinding-and-fresh-registry.md) — Create `ComponentRelease` before `ReleaseBinding`, rebuild when fresh local Harbor lacks the Git-pinned digest, gate the data-plane agent on addon CRDs (capped apply backoff), and gate on workload readiness (#103, #200, #201, #246).
- [OpenSearch ActiveProcessorCount OOMKill in k3d](gotchas/opensearch-jvm-processors-in-k3d.md) — Pin `-XX:ActiveProcessorCount=1` so OpenSearch in k3d doesn't size thread pools for host CPU cores and OOMKill every 45 minutes (#49, #205).
